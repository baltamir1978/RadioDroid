# RadioDroid

En el móvil se llama **FMDroid**. Radio por internet con reconocimiento de canciones, letra sincronizada, widgets y Android Auto.

Versión para Android de RadioApp (repositorio privado), la app de iOS. No es un port:
se escribe desde cero, con la app original como especificación.

**Estado: primera versión, sin probar aún en un móvil** (5-nov-2026). Ver `CLAUDE.md`.

## Pila

Kotlin + Jetpack Compose, para **Android 12 o posterior**, también en **GrapheneOS** (sin los servicios de Google).
